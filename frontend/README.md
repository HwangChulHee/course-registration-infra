# 수강신청 프론트엔드 데모

React + TypeScript + Vite 기반 Mock 앱입니다. 서버, 실제 인증, DB 및 AWS 연결은 없습니다.

## 실행

Node.js 20.19+ 또는 22.12+ 권장. 이 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시되는 주소(기본 http://127.0.0.1:5173)를 엽니다.

```sh
npm run typecheck
npm test
npm run build
```

## 시연 경로

1. 김하늘 `haneul@example.com` 또는 이바다 `bada@example.com`으로 로그인합니다. 공통 시연용 비밀번호는 `demo1234`입니다.
2. 또는 회원가입 탭에서 가상 이름/이메일과 같은 공통 비밀번호로 가입 후 로그인합니다. 비밀번호는 저장하지 않으며 실제 비밀번호를 입력하지 마세요.
3. 오픈 전에는 입장이 비활성화됩니다. 페이지 맨 아래 `개발자용 시연 설정`을 펼쳐 `지금 오픈하기` → `수강신청 입장`을 누릅니다.
4. 24개 강의를 이름/코드/교수로 검색하고 분야·신청 가능 여부로 필터링합니다.
5. `프로그래밍 기초`는 마지막 한 자리가 남아 있습니다. 신청하면 인원이 증가하고 신청 완료·취소 버튼이 표시됩니다. 중복 신청 버튼은 제공되지 않으며 도메인 로직에서도 중복을 거부합니다.
6. `컴퓨터개론`은 처음부터 마감입니다. 마감 이유와 비활성 버튼을 확인합니다.
7. `내 신청 내역`에서 취소합니다. 정원이 회복되고 다시 신청할 수 있습니다.
8. 신청을 남겨둔 채 로그아웃 후 다른 계정으로 로그인/입장하면 본인 내역만 보이고 전체 정원에는 앞 계정 신청이 반영됩니다.
9. 새로고침하면 계정, 세션, 오픈·입장 상태 및 신청 내역을 복원합니다. `오픈 전으로 변경`은 신청을 유지하며 입장을 해제합니다.
10. `데모 초기화` 확인 시 가입 계정과 신청을 지우고 기본 계정/강의, 로그아웃·오픈 전 상태로 돌아갑니다.

## 구조 및 한계

- `src/domain.ts`: 타입, 시드, 신청/취소 규칙
- `src/repository.ts`: 저장소 인터페이스의 localStorage 구현 및 복원 검증
- `src/main.tsx`: 화면과 사용자 동작
- `src/style.css`: 반응형 스타일
- `src/domain.test.ts`: 입장 제한, 마감, 중복, 취소/재신청, 사용자 분리 검증

localStorage는 `campus-registration-demo-v1` 키를 사용합니다. 저장이 차단되면 화면에 경고하고 현재 메모리에서 계속 동작합니다. 잘못된 저장 데이터는 초기 상태로 복구하고 알립니다. 인증은 공개된 공통 비밀번호를 확인하는 시연용 동작입니다. 단일 탭 내 상태 일관성만 검증하며 여러 탭·기기·실제 동시 요청의 안전성을 보장하지 않습니다. 백엔드 연결 시 저장소와 인증 동작을 교체해야 합니다.

신청·취소 완료 및 오류 메시지는 작은 중앙 모달로 표시합니다. 확인 버튼 또는 Escape로 닫을 수 있으며 로그인 성공·강의 목록 입장 시 안내 팝업은 표시하지 않습니다.

오픈 상태 전환과 데모 초기화는 페이지 맨 아래의 `개발자용 시연 설정`을 열어 조작합니다. 기본은 접힌 상태이므로 대기 화면 캡처 시 제어 버튼이 표시되지 않습니다.
